# Divisibility Challenge

A React + Vite web game using the numbers 1 to 100.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vite writes the deployable site to `dist`.

## Cloudflare Pages settings

- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
